# 🎬 Movie Data Analysis with PostgreSQL

## Description

Projet d'exploitation et d'analyse d'un jeu de données
cinématographiques à l'aide de PostgreSQL.

L'objectif est d'explorer les caractéristiques des films,
leurs budgets, leurs revenus, leurs genres, leurs réalisateurs
et leurs acteurs.

## Objectifs

- Importer un jeu de données CSV dans PostgreSQL
- Nettoyer et préparer les données
- Explorer les données avec SQL
- Analyser les revenus et budgets des films
- Étudier la rentabilité des films
- Étudier la relation entre budget et revenu
- Produire des indicateurs statistiques
- Préparer les données pour une analyse économétrique

## Technologies

- PostgreSQL
- SQL
- Python
- Pandas
- Matplotlib
- Git / GitHub
